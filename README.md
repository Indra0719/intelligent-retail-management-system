# Intelligent Retail Management System (IRMS)

AI-Driven Pricing and Coupon Automation for E-commerce

## Executive Summary
IRMS is a production-grade full-stack MERN application that automates pricing decisions, coupon generation, and inventory analysis using AI. It eliminates manual pricing work and enables data-driven decisions powered by Groq Llama 3.1.

## Tech Stack
- Frontend: React (Vite), Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB (Mongoose)
- AI: Groq API (Llama 3.1)
- Auth: JWT (role-based)
- Image Upload: Cloudinary + Multer
- Scheduling: node-cron

## Key Features
- Dynamic Pricing Engine with urgency scoring
- Automated Coupon System (4 types)
- AI-Powered Inventory Insights
- Analytics Dashboard
- Role-based Authentication

## Setup
cd backend && npm install && npm run dev
cd frontend && npm install && npm run dev
